# Reproducibility Protocol for Functional Profile Analysis (Figure A & B)

This figure illustrates the significant differences in KEGG metabolic pathways (Level 3) among three wild herbivore species (Blue sheep, Siberian ibex, and Marco Polo sheep) during Summer (A) and Winter (B).

## 1. Data Processing and Transformation
- **Functional Annotation:** Metagenomic data were mapped to the KEGG database.
- **Normalization:** Relative abundance of pathways was calculated.
- **Transformation:** To reduce skewness and stabilize variance, data were $\log_{10}(x+1)$ transformed before statistical testing and visualization.

## 2. Online Analysis Platform
- **Tool:** [GenesCloud DiffStat Module](https://www.genescloud.cn/chart/DiffStat)
- **Input:** A pathway abundance matrix with species grouping information.

## 3. Statistical Analysis
A robust non-parametric workflow was employed to identify differentially abundant pathways:
- **Global Test:** The **Kruskal-Wallis (KW) H test** was used to determine if there were significant differences among the three species for each pathway.
- **Post-hoc Test:** For pathways with a significant KW result, **Dunn’s test** was performed for pairwise comparisons between species.
- **Multiple Testing Correction:** P-values were adjusted using the **Benjamini-Hochberg (FDR)** method to control the false discovery rate.
- **Significance Level:** Only pathways with an adjusted P-value < 0.05 are displayed. In the "Dunn test" column, `*` indicates significant pairwise differences.

## 4. Visual Refinement (Adobe Illustrator)
Following reviewer suggestions for manuscript-wide color consistency:
**Color Standardization:** The original colors generated by GenesCloud were manually updated in **Adobe Illustrator (AI)**. 
**Layout:** Panels A (Summer) and B (Winter) were aligned, and text labels (pathway names, P-values) were polished for readability.

## 5. Software and Tools
- **GenesCloud:** For statistical computation and base plot generation.
- **Adobe Illustrator:** For final aesthetic adjustments and color unification according to peer-review feedback.
